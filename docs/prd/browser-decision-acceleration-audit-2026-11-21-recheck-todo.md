## Release blockers

- [x] **B01 | Use the execution ID for every durable task write, and keep lane ownership separate** (D-FR-07–10, M-FR-07). `src/service/ManagedBrowserAiToolService.ts:2064,2115–2133,2196–2239` admits and finishes under `executionId` but records cursor/intent/outcome under the control `taskId`. The real intent upsert supplies only the ID and intent (`src/modules/BrowserTaskModule.ts:110–119`); the SQL entity requires other non-null columns (`src/entity/BrowserTask.entity.ts:26–48`). A new task's ordinary action can fail before dispatch; a preexisting control-ID row could receive another execution's journal. The integration test independently mocks these writes (`test/vitest/main/managedBrowser/managedBrowserAiToolService.executeTask.test.ts:133–165`). Nested termination also still closes the enclosing lane between calls, and reopening at the next execution can reopen a canceled control (`src/service/browserDecision/BrowserTaskRunner.ts:2487–2498`, `src/service/ManagedBrowserAiToolService.ts:2196–2204`). Use the execution ID through the whole journal; only the outer owner should terminalize the lane. Verify one real SQLite row through admission, action and terminal state; two nested calls; and Stop between calls.
- [x] **B02 | Separate a normal approval or credential reply from a user takeover** (D-FR-10a/15a/26, C-FR-05–09). `awaitRunnerApproval` restores control via `resume`, which increments the generation (`src/service/ManagedBrowserAiToolService.ts:1133,1157–1201`, `src/service/browserAgents/AgentTaskControlService.ts:341–351`). A benign in-memory runner probe using the same transition confirmed approval produced zero actual redispatches. Conversely, credential/picker completion only ends the intervention span and can leave the accelerated runner at a closed gate; standalone child sign-in omits `controlTaskId` (`src/service/browserLogin/BrowserCredentialLoginService.ts:52–78`, `src/service/browserAgents/AgentTaskControlService.ts:272–283`, `src/service/ManagedBrowserAiToolService.ts:2036–2047,2338–2356`). Accelerated child approval proposals are still flattened into a known/empty result (`ManagedBrowserAiToolService.ts:802–811,1417–1453` and `BrowserTaskRunner.ts:1928–1939` under `src/service`). Use explicit transitions for normal wait release versus takeover; carry the bounded consequential-action proposal to the parent. Verify real card approval, refusal, credential submit, picker, Stop, expiry and actual takeover for both executor paths.
- [x] **B03 | Fix the complete fast-runner result and start contract** (M-FR-02/07/09/12). `src/service/agentTools/runBrowserTasksTool.ts:824–871` reads `started.session_id` while `src/service/ManagedBrowserAiToolService.ts:478–501` returns `sessionId`, so normal fast execution does not receive the launched session. That adapter also drops the requested proxy, does not carry the lane signal into start, omits the session from the result needed by `keep_open`, and maps partial/canceled/needs-user outcomes inconsistently with the collector. Make the adapter typed end to end and share the validated lane envelope with AgentRuntime. Verify start→execute→terminal on the actual service, using both `keep_open` modes, explicit proxy, Stop during launch, and partial/handoff results.
- [x] **B04 | Keep browser policy URLs inside the trusted boundary** (D-FR-12, A-FR-06/08/15, A-AC-01). The new `policyUrl` bypasses display URL sanitization and travels in the general observation returned by both `browser_observe` and `browser_run_actions` (`src/childprocess/managed-browser/BrowserObservationService.ts:555–560,584–588`, `src/modules/ManagedBrowserModule.ts:1442–1450,1487–1497`, `src/service/ManagedBrowserAiToolService.ts:574–582,1000–1004`). A preserved internal navigation address must not be a model or renderer field. Use explicit public projections on direct observations, action results, nested final observations, status/events, and logs; keep trusted route data on a separate internal interface. Audit the remaining pre-truncation text, field-history stamps, untyped recipe-key rewriting, and worker error sanitization (`BrowserObservationService.ts:468,542–575`, `WorkerSession.ts:907–915` and `index.ts:314–317` in the worker directory). Require contract and safe synthetic-data coverage across every output path. Static defensive review only.

## Batch and control follow-ups

- [x] **C01 | Enforce scheduler limits where inference actually runs** (M-FR-06/10/12). The global counter holds a slot for the whole lane, including human waits, and is neither route- nor provider-specific. The wait queue does not wake on abort; a canceled acquire can fall through to work and decrement a slot it never held (`src/service/agentTools/runBrowserTasksTool.ts:197–221,959–978,1062–1066`). Production executors do not return `tokensUsed`; charging checks only the initial mock-shaped result and misses retry, actual cost and 429 backoff. Use cancelable acquisition with one release per granted slot, an appropriate provider scope, and actual usage/attempt accounting before and during work. Qualify account contention from structured holder state, late cancellation and per-site admission after navigation, not only at launch (`src/modules/ManagedBrowserModule.ts:157,689–704,797`). Verify two unrelated routes, waiting versus active lanes, Stop while queued, retry and aggregate-budget exhaustion on both executors.
- [x] **C02 | Apply the batch consent grant and persist the selected model** (M-FR-04/11/12). Missing confirmation now fails closed. `hasRoutineGrantForAgentTask` has no production caller and the grant stores IDs without site/action scope (`src/service/agentTools/runBrowserTasksTool.ts:288–305`). Tie a scoped, expiring approval to actual routine-action dispatch; retain separate consequential approvals. `batchSubAgentModel` is sent and parsed but omitted by the preference merge (`src/views/components/settings/ManagedBrowserSettingsPanel.vue:805`, `src/modules/ManagedBrowserSettingsModule.ts:62–66,193–209,419–461`); a benign module probe confirmed a save drops the key. Verify expiry, scope change, revocation and model save/reload including unrelated settings/probe writes and provider-bound availability.
- [x] **C03 | Fix continuous user-wait accounting and deliver resume notes to live consumers** (D-FR-10a, C-FR-07/09/14, C-AC-03). Parent polling can expire at its original deadline during an active wait (`src/service/AIChatQueryLoop.ts:6577–6580,6603–6628`); the watchdog begins after confirmation, and intervention state issues also affect credential/picker waits (B02). `src/service/AgentRuntime.ts:671–695` only appends a persisted transcript from the outer pause callback; the nested runner can consume the note first while the outer loop is waiting on its tool (`src/service/browserDecision/BrowserTaskRunner.ts:529–564`). Deliver the note per generation to the next actual decision and live outer model turn without replay. Verify a 45-minute wait across the original deadline, sibling completion, confirmation wait, individual expiry, Pause/Resume mid-tool and Stop.
- [x] **C04 | Route all live controls and handoffs across sibling sessions** (C-FR-04–08/10/12/15/16, M-FR-08/13). Sparse fields are retained now, but production session cards can ignore a second active session and clear the displayed session on another terminal event (`src/views/components/aiChatV2/ManagedBrowserSessionCard.vue:435–464,673–686`). The new queue releases its claim without automatically promoting the next waiter (`src/views/components/aiChatV2/handoffDialogQueue.ts:12–35`). Verify two sibling handoffs, badge/count, auto-promotion, task-specific focus, UI control rejection, actual takeover title without page mutation, repeated unexpected changes, and closing/reopening one of several windows.
- [x] **C05 | Verify leases, cleanup and result validity before terminal transfer** (M-FR-06–09/11). Missing lease can still reach the owner change and rollback relies on a lease object that can be mutated in place (`src/modules/ManagedBrowserModule.ts:1159–1195`). A first stop failure can skip cleanup for other owned sessions; callers still ignore some `failedSessionIds` and Clear All has no retained-session cleanup (`src/service/agentTools/runBrowserTasksTool.ts:1113,1225–1266,1323,1534`, `src/main-process/communication/ai-chat-v2-ipc.ts:1749–1777`). Verify missing lease, rollback to immutable prior owners, malformed completed results, late sibling cleanup, both conversation-clear paths and parent readback of externalized output.
