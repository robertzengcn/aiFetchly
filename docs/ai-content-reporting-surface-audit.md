# AI Content Reporting — Surface Audit (P1)

Companion to `docs/prd/ai-content-reporting-prd.md` §8.2 / §16 Phase 2.

This is the release-checklist record of which AI-output surfaces have the
**Report AI output** action and which P1 surfaces remain. Per PRD §8.2 / §16,
any P1 surface that remains accessible in the Store build must either gain the
action or be disabled in that build, with the rationale recorded here.

## Decision

Before the next Store submission, re-run this audit. For each P1 row still
marked ⏳: either integrate `AIContentReportButton` (reusing the shared
contract/Zod schema/IPC/service) **or** gate the surface out of the Store build
and record the gating rationale here. PRD §16 Phase 2 requires that any P1
surface accessible in the submitted package ship with reporting in the *same*
submission.
